## Reasoning

The user's requested flat file list (`PROJECT.md`, `TASKS.md`, `STATE.md`, `FILE_INDEX.md`,
`ARCHITECTURE.md`, `API.md`, `DATABASE.md`, `DECISIONS.md`, `CHANGELOG.md`, `PROMPTS.md`,
`CURRENT_CONTEXT.md`, `SESSION_LOG.md`, `TODO.md`, `WORKLOG.md`) was explicitly offered as
improvable ("you may redesign this if you have a better structure"). I consolidated
`CURRENT_CONTEXT.md` into `STATE.md`, and `WORKLOG.md`/`TODO.md` into `TASKS.md` + `sessions/`,
on the reasoning that more files answering overlapping questions is what causes these systems to
rot — an agent updates whichever one it happened to open and the others silently go stale. Full
rationale recorded in `.ai/README.md`. I added `MIGRATIONS.md` and `WORKFLOW.md` beyond the
requested list because "track migrations" was a distinct explicit requirement not covered by
`DATABASE.md` alone, and a worked example was requested as a top-level output item.

The root pointer files (`CLAUDE.md`/`AGENTS.md`/`GEMINI.md`/`.cursorrules`) are the mechanism
that makes onboarding *automatic* rather than dependent on a human remembering to paste a
bootstrap prompt: each tool already auto-reads its own convention-named file, so making all four
converge on `.ai/BOOTSTRAP.md` means "read this first" happens without any human action.

`.ai/` was left git-tracked (not gitignored like `docs/`/`Plan.md`) on the reasoning that it's
operational state, not the deep design rationale the project owner wanted private — see the
`DECISIONS.md` entry on this, which flags it as reversible if the project owner disagrees.

## Warnings for whoever picks this up

- `.ai/scripts/validate.py`'s path-existence check is best-effort regex over markdown, not a
  real markdown parser — it can still miss non-standard link formats. Treat a clean run as "no
  known drift," not a formal guarantee.
- The `.ai/checkpoints/M0-scaffolding-complete.md` checkpoint was written in the same session
  that completed the milestone it snapshots — going forward, checkpoints should be written
  promptly at milestone boundaries, not batched, or they lose the "what did it look like right
  then" value that makes them worth the extra file.
