## Reasoning

Bedrock was chosen as the default provider behind an `EmbeddingProvider`/`LLMProvider`/
`Reranker` interface specifically so "Bedrock default" and "open-source benchmarked" aren't in
tension — see ADR 0007. PubMedQA and MedQA were given deliberately different evaluation roles
(IR metrics vs. end-to-end MCQ accuracy) rather than forcing the same metrics on both, because
MedQA has no per-passage relevance labels and fabricating them would produce misleading numbers
— see ADR 0012. Docs were grouped by theme under `docs/` (product/architecture/retrieval/
evaluation/planning/engineering/risks) rather than flat-numbered, per the project owner's
explicit choice.
